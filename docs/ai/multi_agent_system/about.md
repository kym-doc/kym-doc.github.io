## 课程简介

主要依照《An Introduction to MultiAgent Systems》2nd Edition这本教材的内容来讲解的。一开始会讲授不少关于古早时期关于 Agent System 的内容，个人认为非常有助于理清楚什么叫做 Agent (而不是看小视频讲解)。之后会讲解一部分强化学习和博弈论的知识。

作业安排上，笔者这个学期总共有两次编程作业和三次课后作业提交。内容包括但不限于：
- 复现一篇简单的[智能体论文](https://www.ijcai.org/Proceedings/91-1/Papers/014.pdf)
- 用Jason语言做合同网协议实现
- 从章老师给出的论文集合里，选一篇关于智能体的论文做口头汇报讲述（论文选取还是比较前沿的）
